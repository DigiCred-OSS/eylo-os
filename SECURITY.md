# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to
[helpdesk@veris.in](mailto:helpdesk@veris.in).

Do not open a public issue or pull request for an undisclosed vulnerability.
Include affected versions or commit IDs, reproduction steps, impact, and any
known mitigations. Do not include credentials, personal data, or other secrets
in the report.

The maintainers will use the reporting address to coordinate validation and
responsible disclosure.
